Before you start

Know what you're getting into

This is not Yaesu firmware

Yaesu doesn't make, approve or support this build, and there is no warranty of any kind. Loading the wrong file or losing power during an update can wipe your settings or leave the radio unusable. Every mod here has been tested on the author's own radio, but that is no guarantee for yours.

Wider TX means legal responsibility

This build lets the radio transmit on HF 1.8–30 MHz with no gaps, on 136–174 MHz, and up to 470 MHz. Transmitting is only legal where your licence allows it. The FTX-1 holds no certification for commercial, public-safety, marine, aviation, CB, GMRS, FRS or MURS use. Spurious emissions and output power outside the factory ham bands haven't been measured. Using those frequencies is entirely on you.

Back up first

Save your memory channels and menu settings with the method in the FTX-1 manual. Put your untouched Yaesu SFL files somewhere safe, because they are your only way back to stock.

How to load firmware Step-by-step with pictures

Do not interrupt the update. Remove the SBR-52LI battery and run the radio from an external power supply. Back up memories and menu settings first; the reset at the end clears them. Do not remove the microSD card or turn the radio off while the update is running. If it is interrupted, the radio will not operate properly, and Yaesu's Firmware Upgrade Manual does not describe a recovery procedure. See the disaster recovery section at the bottom if the DISPLAY update leaves a black, frozen or looping screen.

You'll need

  • An external DC power supply. For a Field-head update, remove the SBR-52LI battery first.
  • A microSD or microSDHC card Yaesu has tested: 2 GB, or 4, 8, 16 or 32 GB, formatted in this radio.
  • The two custom files, named exactly FTX-1_MAIN_V0113.SFL and FTX-1_DISPLAY_V0110.SFL (upper case).
  • Copies of the stock MAIN and DISPLAY files, kept somewhere other than this card, for rollback.
  • A computer to check the SHA-256 hashes and copy the files onto the card.

Prepare the card and files

Format the card in the radio before you copy anything onto it. Formatting erases the card. The custom MAIN and DISPLAY files depend on each other, so copy both into the same FTX-1 folder and flash them together.

  1. Back up memories and menu settings. Press and hold [FUNC], then choose EXTENSION SETTING → SD CARD. Touch DONE for each data item you want to save. The Operating Manual shows “Saving memory data” and “Save setting menu data.” To keep a new file, touch NEW, enter a name of up to 15 characters, then ENT. FILE SAVED appears when it is done; touch the screen, then press [BACK] until you return to normal operation.
  2. Format the microSD card in this radio. Use a card already formatted here if you have one. Otherwise: press and hold [FUNC], choose EXTENSION SETTING → SD CARD, then touch DONE on FORMAT. Touch OK to initialize, or CANCEL to stop. When FORMAT COMPLETED appears, touch the screen, then press [BACK] until you return to normal operation. Cards formatted on another device may not work until you format them in the FTX-1.
  3. Check the SHA-256 hashes. Compare each file with the values in README or SHA256SUMS before you copy it. On Windows, run the commands below in the folder that holds the files.
  4. Copy both files into the FTX-1 folder. Put FTX-1_MAIN_V0113.SFL and FTX-1_DISPLAY_V0110.SFL directly under FTX-1. Do not put them in Capture, MemList, Menu, PlayList or QSOLog. If they are anywhere else, the radio will not recognize them.

Load the firmware

These steps follow the Firmware Upgrade Manual when MAIN is already later than V01.00, which it is on the current custom builds (they are based on V01.13). That is the manual's step 11 onward. If MAIN is still V01.00, use the bootloader steps in the next section first.

  1. Turn the transceiver off. The manual starts the update with the radio off.
  2. Remove the battery and connect external power. For a Field-head update: remove the SBR-52LI, then connect an external power source. If you are also updating an FTX-1 Optima or SPA-1, connect the Field head to the SPA-1, then connect external power.
  3. Insert the microSD card. With the radio still off, insert the card into the slot with the contact face on the front, until you hear a click. The Operating Manual says to insert and remove it firmly so it does not pop out.
  4. Turn the transceiver on. This is the manual's step 11, used when MAIN is not V01.00.
  5. Press and hold the [FUNC] knob. This opens the setting menu.
  6. Touch EXTENSION SETTING. If you do not see it, touch FWD → to bring it up, then touch it.
  7. Open the firmware list. Touch SD CARD, then touch DONE on the FIRMWARE UPDATE item.
  8. Mark DISPLAY and MAIN only. A check mark means that file will be updated. Ready means the file is on the card and can be updated; the manual also says Ready appears when the version already matches and an update is not necessary. These custom files keep the stock names, so Ready may appear even though you still need to load them. Touch an empty box to mark it. Mark DISPLAY and MAIN, and leave DSP, SDR and OPT unmarked unless you are installing official Yaesu files for those. Then touch UPDATE. Touch CANCEL if you need to stop.
  9. Touch OK on the UPDATE? screen. The confirmation screen is headed CAUTION and asks UPDATE? Touch CANCEL to stop instead.
  10. Wait until the radio restarts itself. A progress indicator appears when the transfer begins. Wait until it finishes. Do not remove the card or turn the radio off. When the update is complete, the power turns off and then on by itself. The manual does not say how long this takes.
  11. Reset the transceiver. For a Field-head-only update, this is the last required step in the manual. Turn the radio off. Then turn it on while holding [BACK] and [FINE/FAST] at the same time. The frequencies should return to 144.000.000 on the SUB side and 7.000.000 on the MAIN side. This reset clears memories and menu settings.

If you are also updating an SPA-1, the manual has a second pass after this Field-head reset (its steps 20–30): hold [FUNC], open SD CARD → FIRMWARE UPDATE, mark only OPT, then UPDATE, OK, wait for the restart, and reset again. This custom build does not include an OPT file.

If MAIN is still V01.00

Skip this section unless SOFT VERSION shows MAIN as V01.00. In that case the manual says not to skip these bootloader steps, then continue from “Press and hold the [FUNC] knob” in the section above (its step 12).

  1. Power on while holding three keys. With the card already inserted and external power connected, press [QMB], [VM MW] and [M►V MT] at the same time, then turn the radio on. The FIRMWARE UPDATE screen appears.
  2. Do not touch the screen. The screen says to touch it to continue. The manual says not to. Go on to the next step.
  3. Turn the [FUNC] knob clockwise five clicks or more. The YAESU BOOT LOADER Vxx-xx screen appears.
  4. Mark DISPLAY only, then touch UPDATE. Do not mark MAIN, DSP or SDR. Wait for the progress indicator to finish. Do not remove the card or turn the radio off.
  5. Reconnect power, then continue the normal update. When this part is complete, the power turns off by itself. Unplug the DC power cord, then plug it back in. The radio turns on by itself. Then go to “Press and hold the [FUNC] knob” above and finish the MAIN update, the reset, and the version check.

Confirm the version

The Firmware Upgrade Manual checks the installed versions this way, both before an update and after.

  1. Press and hold the [FUNC] knob.
  2. Touch EXTENSION SETTING. If it is not on the first page, touch FWD →, then touch it.
  3. Touch SOFT VERSION. Each firmware version appears on the TFT. OPT appears only when the Field head is connected to an SPA-1. After this custom update, DISPLAY should read V01-10 and MAIN should read V01-13. The custom files keep those stock version numbers, so this screen cannot tell custom firmware from stock.

To put your memories and menu settings back after the reset, the Operating Manual's “Reading Memory and Set Menu data” steps are: press the [FUNC] knob, choose EXTENSION SETTING → SD CARD, touch DONE on the data item to be read, touch the file name, then OK on the overwrite confirmation. FILE LOADED appears when it is done; touch the screen. The radio then turns off and back on. The manual notes that with some OEM cards the screen may stay blank until you remove the card.

If something goes wrong

  • (No such file) means that item is not in the FTX-1 folder, or the file name does not match. Check that both files sit directly under FTX-1 and are named exactly FTX-1_MAIN_V0113.SFL and FTX-1_DISPLAY_V0110.SFL.
  • (Broken file) means the file is corrupt. The manual says to download the firmware again from Yaesu and start over. For these custom files, copy the checksummed files again, confirm the SHA-256 values, and start over.
  • If the radio never lists the files, they are probably in a subfolder such as Capture or Menu, or the card was not formatted in this radio.
  • If you formatted the card after copying the files, the files were erased. Format first, then copy them again.
  • If the update is interrupted, the manual says the radio will not operate properly and does not give a recovery procedure. If the DISPLAY firmware may be corrupted, use the disaster recovery section below.
  • After a successful reset, memories and menu settings are cleared. Load the backup from the card as described above.

To roll back to stock, flash the stock FTX-1_MAIN_V0113.SFL and FTX-1_DISPLAY_V0110.SFL files the same way, together. Before you go back to v7 or to stock from a v8 or later build that added extra dial steps, first set SSB/CW DIAL STEP to 5, 10 or 20 Hz, MAIN STEPS PER REV to 50, 100 or 200, and FINE/FAST KEY to NORMAL. Older firmware misreads the new settings.

Disaster recovery: corrupted DISPLAY firmware

Use this section if a DISPLAY load is interrupted or fails and the radio is left with a black or frozen screen, or it boot-loops.

No verified user recovery method is documented for a dead FTX-1 display. Yaesu does not describe how to recover a black, frozen or looping screen, and it does not document a USB or serial programmer for this radio. Do not invent or try undocumented key combinations. A third-party guide that uses different keys than Yaesu's manual should be ignored.

What Yaesu documents. The FTX-1 Series Firmware Upgrade Manual (2511-C) says not to remove the microSD card or turn the radio off while updating, and that if the update is interrupted the transceiver will not operate properly. It does not then give a recovery procedure. If you need help, it says to consult a Yaesu sales site or service center. Yaesu USA is listed in that same manual at 6125 Phyllis Drive, Cypress, CA 90630. Firmware is loaded from a microSD card. The only power-on key combination Yaesu documents for a firmware update is: while holding [QMB], [VM] and [M►V], turn the radio on. The FIRMWARE UPDATE screen should appear; do not touch it; turn [FUNC] clockwise five clicks or more to reach the YAESU BOOT LOADER, then mark DISPLAY only and touch UPDATE. The manual presents that path only when MAIN is V01.00, as the first DISPLAY update, not as a general recovery method for a later radio or a blank screen. Yaesu also says a (Broken file) status means the file on the card is corrupt, and that you should obtain the firmware again and start over. The Operating Manual (p. 64) says to format the card in the radio; cards formatted on other devices may not work until they are formatted in the FTX-1.

What SQ9PD documents. SQ9PD's FTX-1 modification notes warn that an error or interrupted update may cause loss of settings, malfunction, or render the radio inoperable, and that you should follow Yaesu's FTX-1 firmware update instructions. His patcher “prepares files; it does not program or repair the radio.” To return to stock he says to install the original unmodified MAIN and DISPLAY following Yaesu's instructions, then do a factory reset.

Related model, for context only — not an FTX-1 procedure. The FT-710 Firmware Upgrade Manual (2211-A) says that if an update is interrupted, follow the instructions on the screen and start again from step 1. The FTX-1 manual does not include that sentence.

If the radio still shows a screen, these are the documented safe steps:

  1. Leave it on external power with the SBR-52LI battery removed.
  2. If you can still use the menus, format a microSD card in the FTX-1, copy the stock FTX-1_DISPLAY_V0110.SFL (and MAIN if you were also loading it) directly into the FTX-1 folder, check the SHA-256 hashes, and retry the menu update. Mark DISPLAY only, unless you also need to reload MAIN.
  3. If the FIRMWARE UPDATE or YAESU BOOT LOADER screen still appears, follow the documented DISPLAY-only bootloader steps with that stock DISPLAY file. Yaesu documents that key combination only for MAIN V01.00; it is included here because it is the only documented way to reach the bootloader, not because a recovery for later MAIN versions or a blank screen has been verified.
  4. If the radio cannot format a card, Yaesu does not document formatting it on a computer. As a last attempt only, some operators format a card as FAT32 on a computer, create an FTX-1 folder, and copy the stock files there, knowing Yaesu warns that cards formatted elsewhere may not be recognized. Then try the bootloader or menu update again if a screen is available.
  5. If the screen stays black or the radio boot-loops and the bootloader never appears, stop and contact a Yaesu sales site or service center. There is no verified user recovery method for that case.

Sources.     📡Transmit
    
    
    HF transmit, 1.8–30 MHz continuoustested on airMAIN · band table  licence-dependent
    Rewrites the HF transmit limits so the whole range from 160 m to 10 m is open, the same coverage the MARS jumper unlocks, without opening the radio.
    
    
    VHF transmit, 136–174 MHztested on airMAIN · band table  licence-dependent
    Replaces the 144–146/148 MHz amateur transmit edges with 136 MHz at the bottom and 174 MHz at the top.
    
    
    UHF transmit up to 470 MHztested on airMAIN · band table  licence-dependent
    Moves the top UHF transmit edge from 440/450 MHz to 470 MHz. The lower edge is unchanged.
    
    
    10 W from the internal batterytested on airMAIN · power limits
    Raises the battery-pack power cap from 6 W to 10 W on HF and VHF. The 430 MHz cap stays where it was. The battery and the DC jack feed the same PA supply rail, so the transistors see the same current at a given voltage either way. You will use up the pack faster and it will run warmer: keep an eye on VDD and turn power down for long overs.
    
    
    SSB transmit filter: 50–4000 Hztested on airMAIN · TX BPF SEL (SSB)
    Puts a sixth, widest choice at the end of the SSB TX BPF SEL list. It uses Yaesu's own TTBF filter slot and works in any region setting.
    
  
    

  
    📡TX range
    
    
    
    
    Transmit 28–75 MHz (10 m through 74.999999 MHz)tested on airMAIN · band table  licence-dependent
    
      
    On US radios, one edge in the transmit-allow table is moved so the radio can transmit continuously from 28.000000 MHz to 74.999999 MHz. 75.000000 MHz stays blocked, so the radio does not switch to the VHF filter path. HF below 28 MHz, VHF, UHF, and the tables for other regions are unchanged from v8.
    
      
    v10: also opens the MARS (USA_MC) region list, which MARS-unlocked US radios use, to 1.8–74.999999 MHz. On v9 those radios keyed only on 6 m and 70.0–70.5 MHz; the frequency turned red but the TX relay never engaged elsewhere. Tested on air by WG3U with v10 from 30 to 75 MHz. SQ9PD's newer release adds a similar MARS MOD; this build is based on his V40.
    
      
    The Field unit's top TX low-pass filter is designed for 30.1–70.5 MHz (Yaesu Technical Supplement EH084M90A). There is no exciter band-pass filter for 56–70 MHz; 56–75 MHz uses the BPF labelled 70–75 MHz. From 60–75 MHz the radio uses the 70 MHz calibration set, which Yaesu's alignment procedure marks UK-only, so on a US radio the power may be low, wrong, or absent. Above about 70.5 MHz harmonics are less filtered. The internal tuner is specified only for HF (1.8–29.7 MHz) and 6 m; use a resonant antenna with the tuner off above 54 MHz. SPA-1 behaviour above 54 MHz is unknown.
    
      
    SWR SCAN presets that sit near the top of 10 m or either edge of 6 m now start and transmit the scan carrier, instead of being refused as they were on v8. BAND-mode scans still stay inside the band.
    
      
    Before the first key-down, read the 70 MHz alignment values (and the 50 MHz ones for comparison) and change nothing. If the 70 MHz values are blank, zero, or very different from 50 MHz, do not transmit at 60–75 MHz. Start at minimum power (0.5 W on the Field, 5 W on an SPA-1) into a 50-ohm dummy load with a wattmeter and a spectrum analyser, use short CW or FM key-downs, and only then raise power. Most of 29.7–75 MHz is not US amateur spectrum — only 50–54 MHz is, and the US has no 4 m band. Transmitting elsewhere in that range needs MARS, CAP, or other authorization.
    
    
    
    
    

  
    🎚️Audio & EQ
    
    
    EQ3 band reaches 3700 Hztested on airMAIN · PRMTRC EQ3 / P EQ3
    The top EQ band could only go to 3200 Hz. It now goes to 3700 Hz in both the normal and processor EQ sets, from the menu, from CAT and on the display. Use it with the wide TX filter to brighten your audio.
    
    
    Wide SSB receive opens upwardtested on airMAIN · SSB passband centre
    On stock firmware, setting WIDTH above 3 kHz spreads the extra bandwidth to both sides. With this mod the passband centre sits at half the WIDTH (plus any SHIFT), so the added bandwidth is all treble. At 3 kHz and below it behaves like stock.
    
  
    

  
    📻AM
    
    
    AM transmit filter: 50–4000 Hztested on airMAIN · TX BPF SEL (AM)
    Adds a 50–4000 Hz entry to the AM TX filter list, the widest the DSP can do. AM and AM-N both use it. The 9 kHz and 6 kHz AM widths only affect receive.
    
    
    Speech processor works in AMtested on airMAIN · PROC sender
    Stock firmware only sends PROC LEVEL to the DSP in SSB. Now it is also sent in AM, and the COMP meter shows compression. The PROC icon still won't light in AM. With PROC on, AM uses the processor EQ set, which stock already did.
    
    
    Notch & contour markers in AMtested on airDISPLAY · filter scope
    The filter scope now draws the NOTCH and CONTOUR markers in AM and AM-N, where stock hides them.
    
    
    AM passband shading & outlinetested on airDISPLAY · filter scope
    The gray passband and filter skirts now appear in AM the way they do in SSB. They are sized to half the AM width on the scope's 0–4 kHz audio scale: AM fills the full span and AM-N covers 0–3 kHz. The scope plots demodulated audio, so a carrier-centred ±5 kHz view isn't possible.
    
  
    

  
    🌊Scope & waterfall
    
    
    One continuous waterfall through TXtested on airDISPLAY · band scope + AF-FFT
    Stock firmware wipes the waterfall each time you key up and again when you unkey. Here the receive and transmit rows run together as one unbroken history.
    
    
    AF-FFT keeps running on transmittested on airDISPLAY · AF-FFT
    The audio spectrum and its waterfall keep drawing while you transmit instead of going blank.
    
    
    Gray passband tracks WIDTHtested on airDISPLAY · filter scope
    The gray shading on the filter scope follows your actual receive WIDTH. Stock always draws it 3 kHz wide.
    
    
    D-MODE long press on any keytested on airMAIN · button handler fix
    A fix to SQ9PD's button pages (his GitHub issue #2). Long-pressing D-MODE in FIX mode only worked when D-MODE was on its original key. Now it works on whichever key and page D-MODE is assigned to.
    
    
    D-TRACE averaging and power-on restoretested on airDISPLAY + MAIN · D-TRACE
    Averaging can be set to OFF, 2, 4, 8, 16 or 32. Your D-TRACE settings are restored at power-on: MAIN puts them in the start-up handshake frame, and the DISPLAY reads them back. Tapping the CW decoder pane no longer opens the oscilloscope pop-up.
    
  
    

  
    ✏️CW
    
    
    On-screen CW decoder v3.5tested on airDISPLAY · scope audio
    It copies Morse from the scope's audio data with a Goertzel tone filter, and it tracks the sending speed from the dit length. At the start of a transmission it holds the first marks and spaces, seeds the speed from their distribution, then plays them back so it locks on faster. On the synthetic test set the character error rate dropped from 18.3% to 4.3%, and from 21.0% to 4.9% at 28–45 WPM. The first characters of a transmission print after a short pause while it locks; in rare cases the first element can be mis-read.
    
  
    

  
    📈SWR SCAN
    
    
    SWR SCAN transmits at the selected scan power in AM. Use a dummy load or a known antenna. Do not scan on 60 m.
    
    
    
    
    SWR SCAN with band sweeps and a shaded plottested on airDISPLAY + MAIN · function menu or soft key
    
      
    Builds on SQ9PD's SWR SCAN window. The sweep is faster: each point is read after 8 meter updates instead of 16, and the trace is smoothed with a [1, 2, 1] average so it stays clean. Spans still cycle 50 kHz, 100 kHz, 500 kHz and 1 MHz, and BAND now scans the whole US band the VFO is in. 10 m is split into 28–29 and 29–29.6 MHz; 60 m has no band scan (ERRM). The PWR key sets scan power to 0.5, 1, 2 or 5 W (default 1 W). On an SPA-1 the scan stays at 0.5 W.
    
      
    SWR SCAN is no longer grayed out when the internal tuner is on. START switches the tuner to THRU, waits for it to report THRU plus 300 ms, runs the scan, then turns the tuner back on. It stays grayed only while a tune is actually in progress, and it shows ERRT if THRU is not confirmed within 2 s. If power is lost during a THRU scan, turn the tuner back on by hand.
    
      
    After a scan, STOP becomes GO MIN and jumps the VFO to the lowest SWR. The screen marks that MIN point, draws the 1.5:1 edges in cyan and the 2:1 edges in orange, and the knob drives a cursor with a frequency and SWR readout. The previous scan stays in gray for comparison, lined up by frequency. The area under the current trace is filled with light yellow and the area under the previous trace with light gray (olive where they overlap). Named error codes explain each refused START (including ERRC if CLAR is on). A leftover clarifier offset that used to block START is fixed.
    
      
    
    
    
    

  
    🎛️Dial & keys
    
    
    Before you go back to v7 or to stock firmware, set SSB/CW DIAL STEP to 5, 10 or 20 Hz, MAIN STEPS PER REV to 50, 100 or 200, and FINE/FAST KEY to NORMAL. Older firmware misreads the new settings.
    
    
    
    
    SSB/CW Dial Step up to 1 kHztested on airMAIN · KEY/DIAL → SSB/CW DIAL STEP
    The list is now 5, 10, 20, 50, 100, 250, 500 Hz and 1 kHz. The default is still 20 Hz, and 5/10/20 behave as before. The step is used for the main dial in LSB, USB, CW-U and CW-L, and for the clarifier in those modes. FAST still multiplies by 10, so 1 kHz becomes 10 kHz, and FINE stays at 1 Hz. RTTY, PSK, DATA, FM, AM and channel steps are unchanged.
    
    
    Main Steps Per Rev: 400 and 800tested on airMAIN · KEY/DIAL → MAIN STEPS PER REV
    The encoder already gives 200 counts per turn, and 200 already moves one tuning step per count, so 400 and 800 cannot be finer. They move two steps per count (400) or four (800): twice or four times as much frequency per turn, always on the dial-step grid. At a 20 Hz step that is 4 kHz, 8 kHz or 16 kHz per turn. 50, 100 and 200 are unchanged.
    
    
    FINE/FAST KEY: NORMAL or INVERTtested on airMAIN · KEY/DIAL item 16
    A new item at the end of the KEY/DIAL menu, after MIC MUTE MODE. NORMAL is stock: a short press toggles FINE (1 Hz) and a hold toggles FAST (×10). INVERT swaps them, so a short press toggles FAST and a hold toggles FINE. Each function keeps its own beep. The setting survives power-off. ALL RESET puts it back to NORMAL.

    Under the hood
    
  
    How the patch is checked
    
  
    Processing pipelinedetailsclick to expand
    The page first confirms the file size and SHA-256, then validates the SFL header and tag CRC. It decodes the payload, which uses a 43-byte additive key. Each original byte is compared with the expected value before its replacement is written. For MAIN, the affected S-record lines are rebuilt with fresh checksums and the added code block (new S-records) is inserted; for DISPLAY, the added code is appended to the decoded image. The payload is then re-encoded, the tag CRC (CRC-32 extended over a 4-byte salt) and length field are recalculated, and the result must match the reference build's SHA-256 exactly. The download button stays disabled until it does. When the page loads, it reads the current anonymous build totals from abacus.jasoncameron.dev (/get/wg3u-ftx1-workshop/main and /display) to show the BUILDS readout. After a verified build, and only then, it sends one plain GET request to abacus.jasoncameron.dev/hit/wg3u-ftx1-workshop/main (or /display) to add 1. These requests carry no firmware data, hashes, filenames, body, query string, cookies or referrer. Like any web request, it reveals your IP address to that service. If the counter is blocked or down, the readout just stays hidden and the patcher works exactly the same. The Content-Security-Policy blocks every other network request.
